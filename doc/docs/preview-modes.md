# Preview modes

Preview lets you inspect the book before exporting. Choose the mode that matches the edition you are preparing.

| Mode | What it shows |
| --- | --- |
| **Book** | A paginated view for reviewing book composition. |
| **PDF View** | The current manuscript rendered as PDF pages, with page navigation and zoom. |
| **Web** | The content as a web publication. |
| **EPUB** | The reflowable reading experience used by ebook readers. |

Use the page controls to move through the book and the zoom controls to inspect details. After changing fonts, page settings, or images, revisit the affected pages.

## What to check

- Chapter openings and page turns
- Text flow and crowded pages
- Image placement and captions
- Headings, quotes, page numbers, and running headers
- Reflow in EPUB mode if you plan to publish an ebook
