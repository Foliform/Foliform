# Writing and design

Write in Markdown or supported HTML, then shape the book's visual presentation
and review the result in Preview. Use these feature guides to find the task you
want to complete.

## Writing

- [Write in the editor](/docs/write-in-the-editor) — organize chapters and review
  your source in the live preview.
- [Markdown and HTML reference](/docs/formatting-reference) — syntax for headings,
  quotes, page breaks, images, and other content.

## Design

- [Add images and assets](/docs/images-and-assets) — import images and set their
  alt text and dimensions.
- [Choose a book style](/docs/book-style) — change typography, color, page setup,
  and chapter starts.
- [Templates and styles](/docs/templates-and-styles) — reuse a saved design across
  manuscripts.

After writing and styling, continue to [Preview and publishing](/docs/preview-and-publishing).
