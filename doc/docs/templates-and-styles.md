# Templates and styles

Templates give you a repeatable starting point for a book's typography and
page design. Foliform includes built-in styles and lets you save your own
custom templates.

## Choose a built-in style

In a manuscript, open the **Style** tab in the inspector and use the
**Template** field to search for and choose a style. The built-in choices are:

- **House Serif** — a warm, literary serif style.
- **Editorial** — a slightly larger serif style with generous margins.
- **Workbook** — a clean sans-serif style with a light page.
- **Studio Dark** — a dark page with light text.

Built-in styles are available in every manuscript. They are fixed presets:
you can apply them and then adjust the manuscript's Style controls, but you
cannot edit or delete the built-in definitions.

## Create a custom template

1. Open a manuscript and choose **Templates** in the top bar. The Template
   Manager opens in a separate window.
2. Select **+ New template**.
3. Give the template a name.
4. Set its font, title size, subtitle size, body size, margins, page size, and
   page background. Choose whether each level-one heading starts on a new
   page.
5. Choose **Save template**.

The Template Manager's font choice applies to every text role. Templates store
the selected font family; Google fonts are downloaded and embedded in each
project when the template is applied.

## Apply and refine a saved template

Return to the manuscript's **Style** tab. Search for the saved template in the
**Template** field and select its exact name. The style is applied to the
current book; it does not change the manuscript text. You can then refine the
title, subtitle, and body fonts independently, adjust line height and colors,
and tune other available Style settings.

Applying a template replaces the current style settings rather than layering
the new style over leftover values from the previous one. Book content,
publishing metadata, and assets remain part of the manuscript project.

## Update or delete a custom template

Open **Templates** from the top bar. Select a saved template in the list to
edit it, then choose **Save template** to update it. Choose **Delete** to
remove the selected custom template. Deleting a template does not remove its
style from manuscripts where it has already been applied.

Custom templates are stored locally with the app's template data. The built-in
styles are not listed in the Template Manager because they are not editable.
