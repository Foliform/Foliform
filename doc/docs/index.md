## The book-making workflow

1. Create or open a project.
2. Write and organize chapters in Markdown or HTML.
3. Choose a style and add images or book details.
4. Review the book in the preview mode for your intended edition.
5. Run the export check, then export PDF, EPUB, or HTML.

Each step keeps your manuscript and its presentation together in the same project.
