# Export a book

When the manuscript is ready, choose **Export** and select an edition. Foliform checks the project before creating the output.

## Choose a format

| Format | Use it for |
| --- | --- |
| **PDF** | A fixed-page edition for printing or sharing. |
| **EPUB** | Reflowable digital reading that adapts to the reader's screen and preferences. |
| **HTML** | A standalone web-readable edition. |

## Review the export check

The preflight check looks for missing image assets and page content that may overflow. Review each finding. Cancel to make corrections, or continue after reviewing the warnings.

## Set PDF options

For PDF, choose the page size, margins, and bleed in the export dialog. These settings apply to that PDF export.

EPUB is created as a reflowable EPUB 3 file. HTML is a standalone web edition. Since each format has different reading constraints, review the corresponding preview mode before exporting.

## Before sharing

Check metadata and page furniture, then open or inspect the exported file in a suitable reader. Review images and chapter breaks in particular.
