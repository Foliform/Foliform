# Write in the editor

The editor accepts Markdown and supported HTML in the same document. Edit the source, then switch to Preview to see how the book is laid out.

## Structure chapters

Use a level-one heading for each chapter. For example:

```markdown
# The first chapter

Start the chapter text here.

## A section

Continue with a section inside the chapter.
```

Level-one headings are treated as chapter headings. The selected style and the **Start every chapter (H1) on a new page** setting determine their page treatment.

## Work with the source

Write and organize the manuscript using paragraphs, headings, lists, links, quotes, and other supported formatting. Use the formatting reference for syntax examples and special page markers.

To set a font for a paragraph, place the cursor in it (or select several
paragraphs), then choose a font from the **Paragraph font** picker above the
editor. The editor adds a font block around the paragraph; the font is retained
in preview and exported editions. Google fonts are embedded in the project, so
save the project before applying one.

## Review your changes

Switch between **Editor** and **Preview** as you work. Check chapter starts, page turns, and content flow after changing the text or style.
