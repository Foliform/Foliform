# Book details and page furniture

Use the **Metadata** tab in the inspector to set the information associated with the publication and the elements that appear on its pages.

## Set publication details

Enter the book title, author, and language. These details are used when preparing exported editions.

## Choose page numbering

The page-number setting can be:

- **None** to hide page numbers
- **Page number** to show the current page
- **Page number of total** to show the current page and total, such as `3 / 24`

## Choose a running header

Set **Running header** to **None**, **Book title**, or **Current chapter title**. The selected running header and page numbering appear on every page, including the first, in the live preview and exports.

Review these elements in Preview before exporting, especially after changing the book title or chapter headings.
