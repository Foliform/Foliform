# Getting started

Foliform is a desktop studio for writing, designing, and publishing books.
It brings your content and its typeset preview together so you can shape both
the manuscript and the reading experience in one project.

![Foliform welcome screen with options to create or open a project](/img/manuscript-welcome.png)

*The welcome screen is the starting point for creating a manuscript or
reopening an existing project.*

## What you can make

Use Foliform to work on Markdown or HTML content, then prepare a book for
print or digital reading. A project can include its own text, images, book
settings, publishing details, and visual style.

The app is designed around a few connected tasks:

- **Write:** edit Markdown or HTML and organize the content of your book.
- **Design:** choose typography, page dimensions, margins, and other book
  styling.
- **Preview:** review a live paginated book layout, or switch to a web or EPUB
  reading view.
- **Publish:** export a PDF, EPUB, or HTML edition.
